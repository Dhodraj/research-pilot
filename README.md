# research-pilot

A design for a research agent. There is no working code yet.

Started in March 2026. The repository holds two files:

- `searcher.txt` is the system prompt. The agent first checks which connectors it has, then searches, filters sources for quality, removes duplicates, and writes up what it found.
- `claude_cowork.json` is an Excalidraw diagram of the workflow. Open it at [excalidraw.com](https://excalidraw.com).

Nothing to install or run yet.
